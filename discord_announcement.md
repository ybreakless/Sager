# 🎉 Introducing Sager v0.2.0 - Your Ultimate Gaming Companion!

Hey gamers! 👋 We're excited to announce **Sager v0.2.0**, the ultimate Windows system tray companion that brings **authentic Steam achievement notifications**, **cloud save backups**, and **Android companion support** to your gaming setup!

## 🌟 Key Features

### 1. **Authentic Steam In-Game Overlay**
- **Official Steam Audio**: Hear the authentic Steam achievement chime (`deck_ui_achievement_toast.wav`) with zero disk lag
- **TopMost In-Game Toast**: Appears seamlessly over borderless, fullscreen, and DirectX games without stealing input
- **Steam Deck Charcoal Design**: Dark navy `#1b2838` background with glowing `#66c0f4` cyan accents and gold trophy badges

### 2. **Sager Android Companion**
- **Offline Trophy Showcase**: View all your unlocked achievements anywhere, anytime - no internet needed
- **Home Wi-Fi Sync**: Sync achievements directly over your local network with one tap (⚡ Sync Now)
- **Zero Cloud Middleman**: 100% private, peer-to-peer on your home LAN

### 3. **Vault Export & Import**
- **1-Click Export**: Save your complete trophy history and game catalogs to a portable `.json` bundle
- **Intelligent Import**: Seamlessly import and merge achievements from other PCs with zero data loss
- **Direct Steam Launch**: One-click `[ 🎮 Open in Steam ]` button to view achievements in the Steam client

### 4. **Zero-Terminal Windowless Automation**
- **Native Windows GUI**: No terminal windows - runs silently in your system tray
- **Auto Startup**: Automatically starts with Windows via `%APPDATA%\...\Startup\Sager.lnk`
- **Ultra-Low Resource Usage**: Uses only **~9.4 MB RAM** with **0.0% idle CPU** when no changes occur

## 🔗 Get Started

1. **Windows**: Download `SagerLauncher.exe` from GitHub Releases to install with one click
2. **Android**: Install `sager-companion-v0.2.0.apk` on your phone
3. **Connect**: Run Sager and tap `⚡ Sync Now` when on your home Wi-Fi
